## Instruction Setup

1. Clone the repository from the link provided on the form.
2. Do composer update and npm run build.
3. Import the provided project_management_system.sql to your mysql database.
4. For logging in, use the credentials below
    * username : demo@example.com
    * password : password123
   If you wish to create new credential, click Create One button and register new account for login.
5. If you didn't import the database, do php artisan migrate --seed.
6. Test and explore the project
